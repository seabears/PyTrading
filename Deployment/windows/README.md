# 라즈베리파이 상태 확인 — Windows 원클릭

같은 폴더의 CMD 파일을 더블클릭한다. PowerShell이나 Python 실행은 필요 없다. 현재 Windows 사용자의 SSH 별칭 pytrading-pi와 기존 SSH 키를 사용한다. 인증키·비밀번호를 파일에 넣지 않는다. SSH 인증이 안 되면 CMD에서 ssh pytrading-pi 접속 설정을 먼저 확인한다.

- 01_상태확인.cmd: 현재 서비스 상태를 표시한다. 중지 상태도 정상적인 조회 결과다.
- 02_실시간로그.cmd: 최근 50줄과 이후 로그를 표시한다. 창 닫기/Ctrl+C는 로그 연결만 종료한다.
- 03_부팅설정확인.cmd: enabled/disabled를 확인한다. 부팅 설정을 변경하지 않는다.

서비스는 pytrading-daily-validation이다. 세 파일은 모두 조회 전용이며 서비스 시작·중지·부팅 자동 등록을 하지 않는다. 어느 폴더에서 실행해도 동작한다. 바로가기를 바탕화면에 만들어 사용할 수 있다.

이 문서의 장비 이름, 사용자명 및 절대 경로는 공개용 예시다. 실제 환경에서는 로컬 값을 사용한다.

## 이번에 확정한 것과 확정하지 못한 것

공식 FAQ에서 일반 모의 로그인 경로는 확인했다. 한국투자 앱 > 메뉴 > 주식 > 모의투자 > 모의투자 로그인, eFriend Plus > 로그인 상단 eFriend 모의투자다. 같은 FAQ는 일부 메뉴가 모의에서 제공되지 않음을 설명한다. 이것이 현재 미국주식 vps의 USD/NAV/정산 화면 지원까지 보장하지 않는다. 미지원 경고가 나와도 실전 계좌로 바꾼 자료를 대신 사용하지 않는다.

공식 해외주식 안내는 통합증거금의 별도 신청과 자동환전 구조를 설명한다. 실제 계좌의 미신청/미적용은 별도 확인해야 한다. 공식 일반 메뉴 ‘보유계좌 서비스 현황’, ‘통합증거금 서비스 신청/해지’의 상태 조회 영역은 후보이며 신청·해지·설정 저장은 하지 않는다.

일반 해외 HTS 도움말 [7613]은 예수금/통합잔고·주문체결 탭과 [7717]기간손익 연결을 설명한다. 수익률은 추정치라는 한계가 있다. 이 일반 도움말은 미국주식 모의 지원이나 내보내기 계약의 증명이 아니다. 번호를 추측해 연 별도7710/7711/7712/7715/7717 도움말 URL은 웹 도구에서 열리지 않아 확인 경로로 채택하지 않았다. 이것도 모의 기능 미지원의 증거는 아니다.

특정 API의 공식 미지원은 기존 조사 근거를 재사용했다: foreign-margin, inquire-paymt-stdr-balance, inquire-period-trans, inquire-period-profit, inquire-present-balance.output2. 같은 경로의 추가 계좌 호출0. 다른 API·앱·HTS·명세가 모두 미지원이라는 결론은 내리지 않았다. 새로 검토한 일반 메뉴/도움말에서도 해외주식 vps 전용 대체 계약과 실제 원본은 확보하지 못했다.

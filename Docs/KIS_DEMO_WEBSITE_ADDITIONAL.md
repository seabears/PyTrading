# 공식 사이트 추가 발견 사항

> 2026-11-01 정책 반영: 아래 내용은 과거 조사 이력이다. 현행 [금지 목록](PROHIBITED_OPERATIONS.md)과 [정책 구현 검증](POLICY_ENFORCEMENT.md)이 우선한다. 통합증거금 필드 설명은 읽기 전용 진단이며 사용·가입·활성화 권고가 아니다. integrated 설정은 거절하고 cash_only 설정만으로 승인하지 않는다. 사용자 확인 초기 가상 현금100000 USD는 이미 별도 기준으로 기록됐으므로 다시 요청하지 않는다. 현재 현금·NAV 및 계좌 미가입 상태와는 구분한다.

확인일: 2026-10-29. 공식 FAQ에서 ‘해외’ 검색22건의 목록을3페이지 모두 검토했고, 자금/잔고 관련4개 답변 본문을 추가 확인했다. 자동 계좌 조회·주문·설정 변경·초기화는 수행하지 않았다.

1. **매수가능액 필드 선택**: 2023-11-28 FAQ는 통합증거금 미신청 계좌의 ovrs_ord_psbl_amt/max_ord_psbl_qty와 신청 계좌의 frcr_ord_psbl_amt1/ovrs_max_ord_psbl_qty를 구분한다. 기존 min(외화 여력) 방식은 보수적 제한이지 통합증거금 계좌를 정확히 정상화하는 완성 구현이 아니다. 실제 계좌의 신청 여부·모의 적용 범위가 미확인인 상태에서 새로운 필드로 승인하거나 USD100000을 현금으로 채택하지 않는다. 후속 어댑터는 확인된 서비스 상태와 공식 필드를 연결해야 한다.

2. **야간 잔고와 FAQ 버전**: 2022-08-10 FAQ는 체결기준현재잔고 대신 inquire-balance.output1.OVRS_CBLC_QTY를 사용하도록 안내한다. 이 답변의 주야간 TR 분기는 2023-05-11 FAQ의 통합 개선 설명과 함께 읽어야 한다. 이후에는 실전 잔고 TTTS3012R을 사용하고 주야간원장구분조회 호출은 불필요하다고 안내한다. 오래된 J계열 분기를 새 코드에 복원하지 않는다. 모의 TR은 현재 계약의 VTTS3012R을 별도 확인한 기존 구성을 유지한다. 오래된 FAQ의 야간 경고를 모든 현재 응답이 비실시간이라는 확정 판정으로 확대하지 않는다.

3. **권리정보 대체 경로**: 공식 FAQ는 기간별권리조회(period-rights, HTS7520 기준)와 권리종합(rights-by-ice, 홈페이지 기준)을 구분한다. 종목의 배당·분할 등 권리정보를 대조하는 후보 경로는 추가 확보했다. 그러나 계좌에 실제 입금된 배당의 순액·세금·입금 시각을 확인하는 계좌 현금 사건 원본과는 다르다. 조회 계약도 계좌번호 입력 없이 종목/기간을 받는다. 이를 RiskLedger의 실제 배당 입금으로 넣으면 안 된다.

4. **검색의 함정**: 공식 홈페이지에서 USD100000 초기금 설명도 검색되지만 해외선물옵션 모의투자 안내(TF07db010000.jsp)이다. 현재 해외주식 vps 계좌의 초기금 증거로 사용할 수 없다. 기존 파생상품 차단 정책 유지.

이전 답변보다 조사 범위를 넓혀 유용한 공식 근거를 추가했다. 다만 현재 미국주식 모의의 USD 체결현금·초기 NAV·최종 비용·계좌 자금 사건을 확정할 근거는 여전히 미확인이다. ‘관련 안내가 전혀 없음’ 또는 ‘사이트 전체가 미지원’으로 표현하지 않는다. 이번 문서 조사는 코드·권한·전략을 변경하지 않았고 자동 검사를 재실행하지 않았다.

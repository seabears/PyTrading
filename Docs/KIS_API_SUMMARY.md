# 현재 허용 상품: 주식·채권·ETF만

ETN을 포함해 그 외 상품은 사용 불허다. 선물·옵션·ELW 구현은 보존하고 전송·구독을 차단한다.
ETF와 ETN은 API를 공유하므로 API 함수 수는 변하지 않는다. 허용 API 219개도 허용 상품에만 사용할 수 있다.
공용 시세·주문·복수종목·실시간 구독과 기존 KIS 수집 경로에서 종목의 상품 종류를 검사한다.
현재 주식 30종목과 기존 주식·ETF 비교 종목은 등록했다. 새 주식·채권·ETF는 실제 종류 확인 후
Config/product-policy.json의 verified_instruments에 등록해야 한다. 미확인 종목은 차단한다.
현재 채권 개별 종목은 등록되지 않았으며, 등록 전에는 개별 채권 조회·주문이 차단된다.
일반 계좌·시장 통계 조회는 유지한다. 대출 삭제·현금 거래 제한·실주문 기본 차단도 유지한다.

# 선물·옵션·ELW 사용 불허

선물·옵션·ELW 구현은 삭제하지 않고 보존한다. 해당 상품의 REST 조회·주문과 실시간 구독은 불허한다.
국내주식 모듈에 포함된 ELW 시세 함수도 같은 제한을 적용한다.
전체 구현 323개 중 **허용 219개(REST 183개·실시간 36개), 불허 104개**다.
`allow_trading=True`로도 상품 불허를 해제할 수 없다. 요청 생성·합성 계약 검사는 계속 가능하다.
현재 상태는 [허용 여부가 표시된 전체 목록](KIS_API_CATALOG.md)과 Config/kis-api-catalog.json의 enabled에서 확인한다.
대출 전용 8개 API의 삭제와 현금 거래 제한은 그대로 유지한다.

# KIS API 구성 요약

기준일: 2026-10-23. 현재 실행 코드와 `Config/kis-api-catalog.json` 기준이다.

대출 관련 8개를 제외하고 상품 API 함수 **323개**를 구현했다. REST 260개, 실시간 구독 63개다.
함수 수는 상품별 요청 생성 함수의 개수이며, 공통 인증 기능은 별도다. 공식 포털의 경로 수와 일대일로 대응하지 않는다.

## 공통 연결 기능

- 인증과 발급 시각·서버 만료를 확인하는 24시간 이내 토큰 재사용
- 실시간 접속키 발급, 해시키 발급, 명시적 토큰 폐기
- 호출 한도 처리와 조회 요청의 제한 재시도
- 연속조회 여부와 원본 응답 커서 반환: 다음 요청의 커서는 API별로 지정
- 실시간 등록·해제, PINGPONG, 복수 레코드 해석
- 암호화 체결 통보 해석: AES-CBC/PKCS7
- 주문 응답 유실 시 자동 재주문 차단과 상태 확인 필요 예외

## 대출 관련 기능 제외

대출·신용융자·주식담보대출·대주 전용 API 8개를 함수와 호출 허용 목록에서 삭제했다.
일반 현금 매매·잔고·증거금 조회는 유지한다.

- 주식 예약주문은 현금 잔고 구분 `10`만 허용한다.
- 대출일자·대여일자 입력과 대차매도 옵션을 차단한다.
- 주문 전송을 별도로 허용해도 대출 제한은 해제되지 않는다.
- 프로젝트 지침에 대출 관련 기능을 추가·복원하지 않도록 기록했다.

제거 목록과 검사는 [대출 기능 제거 보고서](../Data/reports/no-loans/report.md)를 참고한다.

## CMD에서 기능 확인

프로젝트 루트 `C:\Projects\PyTrading`에서 실행한다.

```cmd
python Code/main.py --test api
python Code/main.py --test unit-api
python Code/main.py --test api-live
```

- `api`: 인증·인터넷 없이 API 계약과 공통 전송 처리를 검사하고 보고서·그래프 생성
- `unit-api`: API 자동 테스트 실행
- `api-live`: AAPL 시세 REST 3개와 실시간 호가만 실제 연결 확인. 계좌·주문 호출 없음

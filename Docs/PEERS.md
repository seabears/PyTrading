# 유사 사업군 테스트

프로젝트 폴더에서 `python main.py --test peers`를 실행한다.
기능 선택 메뉴의 10번에서도 실행할 수 있다. 회사 목록·사업군·기준 종목·사업 근거는
`../Config/peers.json`, 비교 실행 코드는 `tools/research_peers.py`에 있다.

삼성전자 반도체 사업 비교 대상으로 SK하이닉스·마이크론을 선택했다.
애플 전자기기 사업 비교 대상으로 LG전자·HP·Dell·Sony를 선택했다.
요청한 Arm·엔비디아·아마존·알파벳·메타·마이크로소프트·테슬라·SpaceX도 추가했다. 총 17개 종목이며 GOOG·GOOGL은
같은 알파벳의 Class C·Class A 주식이다. 서로 독립 회사 표본으로 집계하지 않는다.
SpaceX는 SPCX, 상장일은 2026-06-12다. `listed_on`이 공통 시험 시작 이후이면 수집·비교 전에
제외하고 사유를 저장한다. 기존 기간에는 예열·시험 표본이 없어 실제 비교 대상은 16개다.
메타·마이크로소프트는 플랫폼·클라우드, 테슬라·SpaceX는 이동수단·우주 사업군으로 분류한다.
Arm·엔비디아는 칩 설계/IP, 아마존·알파벳은 플랫폼·클라우드 사업군으로 구분한다.
전자는 삼성전자에서 고른 가격 규칙, 후자는 애플에서 고른 가격 규칙을 고정 적용한다.
이는 규칙의 전이 비교이며 같은 사업 모델을 가진다는 뜻은 아니다.
가전·PC·게임·엔터테인먼트 등 매출 구조가 달라 완전히 동일한 경쟁사로 해석하지 않는다.
국내·미국 시세로 비교하며 홍콩 상장 스마트폰 회사는 이번 수집 범위에 포함하지 않았다.

기준 두 종목의 훈련·검증에서 고른 규칙을 고정하고 다른 회사에 재최적화 없이 적용한다.
공통 시험 기간은 2025-11-06~2026-06-12이며, 가격·거래량 규칙과 시장 추세·VIX를 추가한
규칙을 각각 적용한다. 지표 사용 시점·비용은 [지표 안내](INDICATORS.md)와 같다.
단순 보유도 같은 초기 자금 10% 비중·비용으로 계산한다.
각 종목은 독립 가상 계좌이므로 시장별 자금 경쟁·포트폴리오 수익은 재현하지 않는다.

실행마다 `../Data/tests/results/peers/날짜-시각`에 결과 JSON·고정 설정·코드 사본·보고서·그래프를 저장한다.
최신 폴더 경로는 `../Data/tests/results/peers/latest.json`에 있다. 과거 원자료는 `../Data/history/daily`에 보관한다.

2026-10-11 결과는 마이크론의 지표 추가만 수익 개선을 보였으나 거래 4건으로 표본 부족이었다.
SK하이닉스·마이크론·삼성전자·애플은 양수지만 단순 보유 미달, LG전자·Dell·Sony는 손실,
HP는 0거래였다. 현재 종목을 사후 선정하고 이미 본 역사 날짜를 사용한 전이 탐색이다.
추가 종목에서는 시장·VIX 조건 적용 후 ARM -0.5231%/1거래, NVDA -0.0894%/1거래,
GOOG +0.1540%/3거래, GOOGL +0.2019%/3거래, AMZN -0.5923%/2거래였다.
알파벳은 기본 규칙 손실에서 흑자로 바뀌었으나 거래 표본이 적고 모두 단순 보유 미달이었다.
수익성 통과로 취급하거나 실시간 전략을 자동 변경하지 않는다.

뉴스 기반 장중 규칙은 별도 검증이 필요하다. 일봉 adjusted=false 자료의 분할·배당·분사,
역사 요율·세금도 미검증이다. 특히 Sony 기업행동을 재현하지 않은 원시 가격 비교는 추가 확인이 필요하다.
Arm은 2023년 9월 상장으로 수집 이력이 다른 종목보다 짧다. 시험 기간과 예열 표본은 동일 기준으로 검사한다.
같은 사업군의 상관된 수익을 독립 거래 표본으로 합산하거나 원화·달러 금액을 합산하지 않는다.

자동 동작 검증은 `python main.py --test unit-research`이며 합성 입력·가짜 응답을 사용한다.

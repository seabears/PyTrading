# 기술적 전략 독립 비교

실행: 프로젝트 루트에서 `python Code/main.py --test strategies`.
사용 중인 Python 3.12 실행 파일을 그대로 사용할 수 있다. 기능 메뉴에도 strategies 항목을 추가했다.
기능별 자동 검증: `python Code/main.py --test unit-technical`.

설정: Config/technical-study.json. 장중(intraday), 일봉(swing), 공통 위험(risk), 시장 국면(regime), 판정 기준(criteria)을 분리했다.
비율 0.005는 0.5%, 0.01은 1%다. stop_atr·trailing_atr는 ATR의 배수다.

장중 전략은 세션 시작부터의 HLC3 가중 추정 VWAP 상향 교차와 거래량 증가를 본다.
일봉 전략은 MA20/60 추세와 63거래일 모멘텀을 본다.
ATR은 True Range의 14봉 단순평균으로, Wilder 평활 방식과 구분한다.
시장 필터는 KODEX 200·SPY의 2일 이상 지연 자료를 사용하며 상승 국면에서만 신규 진입한다.
필터 없는 경우도 같은 조건으로 비교해 필터의 효과를 숨기지 않는다.

모든 신호 매매는 다음 봉 시가 가상 체결, 당일 고점·ATR은 다음 봉 손절부터 반영한다.
추적 손절선은 한 번 올라가면 ATR이 늘어도 낮추지 않는다.
초기 자금의 최대 10% 투자, ATR 기준 0.5% 위험 예산, 일일 손실 1% 시 신규 진입 중단을 적용한다.
갭 하락·비용 때문에 손실이 예산을 넘을 수 있다. 최대 낙폭은 평가액 기록 시점 기준이다.

Data/history의 실제 저장 토스 자료를 읽는다. 인증·API·주문 호출은 하지 않는다.
장중 자료는 삼성전자·애플 두 종목만 있어 같은 날짜의 일봉 전략과 먼저 비교한다.
일봉은 저장된 15종목으로 확대한다. 각 종목은 독립 계좌이며 수익을 공동 포트폴리오로 합산하지 않는다.
GOOG는 GOOGL과 동일 회사라 중복 제외, SPCX는 저장된 장기 자료가 없어 제외한다.
수집된 과거는 이미 본 자료이므로 탐색이다. 수익이 나와도 독립 검증으로 부르지 않는다.

결과: Data/tests/results/technical-strategies/<실행시각>/report.md, results.json, matched.png, daily.png.
실행 전 조건·비용을 declaration.json에 기록하고 원자료 해시·실행 코드를 보존한다.
Sharpe는 일별 계좌 수익률·252거래일·무위험 수익률 0%로 계산한다.
PF는 손실 거래가 없으면 정의하지 않는다. 승률과 평균 이익/평균 손실도 함께 기록한다.
기존 기본 실시간 뉴스 전략을 자동 교체하지 않는다. 새 전략은 연구 기능이며 실제 주문도 추가하지 않았다.

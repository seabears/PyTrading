# 별도 가격·거래량 연구 실행

운용 설정 `Config/strategy.json`은 실적 검증 조건을 유지한다. 가격 연구는 별도 `Config/strategy-price-research.json`에서 일반 뉴스·실적 조건만 끈다. FMP는 사용하지 않는다.

## 과거 자료 평가

```cmd
cd /d C:\Projects\PyTrading
python Code/main.py --test price-research
```

저장된 30종목 실제 KIS 분봉으로 기본 비용·비용 두 배·기간 전반/후반을 비교한다. 공동 가상 USD 자금, 현행 가격·거래량·매도 규칙과 안전장치를 사용한다. 현재 공통 기간은 2026-09-18~2026-10-21이며 이전 연구에서 본 자료다. 새 독립 평가나 장기 안정성 증거로 해석하지 않는다.

결과·종목 대조·설정·원본 해시·검산·그래프: `Data/reports/price-research/`. 과거 실행 결과는 `Data/tests/results/price-research/`에 보존한다.

## 실제 시세로 지속 모의 관측

```cmd
python Code/price_paper.py
```

추가 인자 없이 계속 실행하며 Ctrl+C로 종료한다. 기존 KIS 인증 파일 설정을 사용한다. 증권사 실제 주문·모의 서버 주문을 제출하지 않는다. 별도 로컬 가상 계좌 `Data/paper-price-research/account.json`을 생성·복원한다. 기존 `Data/paper-kis` 계좌는 사용하지 않는다.

`main.py`도 동시에 켜면 같은 API 키의 호출량이 합산된다. 연구 관측 중에는 한 실행만 운용하는 것을 권장한다. 일정 간격으로 수집·판단하므로 호가가 빠르게 바뀌는 체결 환경을 재현하지 못한다.

일별 JSON·Markdown은 `Data/paper-price-research/daily/`에 자동 갱신한다. 현지 거래일·마지막 관측 시각·평가액·매수/매도 수·실현 손익·판단 차단 사유를 기록한다. 관측 낙폭은 관측 사이 급락을 포함하지 못한다. 당일 첫 유효 관측 직전 평가를 기준으로 하며 증권사 공식 일별 손익이 아니다. 과거 시세로 이 일별 실시간 기록을 소급 생성하지 않는다.

한 번만 실제 연결을 확인하려면:

```cmd
python Code/main.py --test price-forward-check
```

이 명령은 실제 인증·시세 조회와 별도 가상 계좌 기록을 한다. 휴장일에는 WAIT만 발생할 수 있다. 지속 실행이 아니며 주문 체결 성능의 검증도 아니다.

## 이후 평가 조건

우선 새로운 정규장 20거래일을 관측한다. 거래 수가 적으면 기간을 늘리고, 유리한 거래만 골라 평가하지 않는다. 새 자료를 보기 전에 규칙·종목·비용을 고정한다. 손익·비용·최대 낙폭·거래 수·일별 손실·수집 누락을 함께 검토한다. 20일 경과 자체가 채택 기준은 아니다.

현재 손실인 단기 돌파 규칙을 실전 채택하지 않는다. 이미 연구한 일봉 저회전 추세 후보는 별도 미사용 자료를 확보한 뒤 비교한다. 반복 조정으로 기존 기간의 손실을 없애는 것을 수익성 검증으로 취급하지 않는다.

실적 자료는 별도 SEC·IR 원문 대조와 발표 전 예상치 확보를 계속 연구한다. 신뢰성 확인 전 실적 사건을 가격 연구 계좌에 넣지 않는다.

이 문서의 장비 이름, 사용자명 및 절대 경로는 공개용 예시다. 실제 환경에서는 로컬 값을 사용한다.

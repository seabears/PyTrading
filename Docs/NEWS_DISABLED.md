# 뉴스 기능 끔

Config/settings.json의 collect_news=false, Config/strategy.json의 news_enabled=false를 적용했다.
기본 실행에서는 뉴스 RSS 수집·뉴스 검색어 파일 읽기·확정 뉴스 파일 읽기를 하지 않는다.
확정 호재 필수 조건과 확정 악재의 매수 차단·매도 조건도 사용하지 않는다.
가격 돌파·거래량·호가·자금 한도·재진입 제한과 가격 기반 손절·이익 보호·평균가격 이탈 매도는 유지한다.
뉴스가 없어도 나머지 매수 조건을 모두 통과하면 모의 매수가 가능하다. 실제 주문 기능은 없다.
시작 로그에 "가격·거래량 (뉴스 기능 끔)"을 표시한다. 판단 기록에도 news_enabled=false를 남긴다.
뉴스 파일과 수집 코드는 삭제하지 않았다. 나중에 두 설정을 true로 바꾸고 재시작하면 다시 사용할 수 있다.
--test news는 사용자가 명시적으로 선택한 개별 기능 실행이므로 필요할 때 직접 실행할 수 있다.
실행 중 설정 자동 재로드는 없으므로 Ctrl+C로 종료한 뒤 같은 명령으로 다시 실행한다.

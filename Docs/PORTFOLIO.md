# 포트폴리오 반복 연구

기존 장중 뉴스 엔진과 독립인 실제 일봉 모의매매다. 실제 주문을 제출하지 않는다.
공동 현금, 최대 3종목, 초기 자금 10%/종목, 다음 거래일 시가 체결·갭 손절·정수 가상 수량·비용을 계산한다.

## 실행

1. `python main.py --test portfolio`: 수정주가 요청 → 시장별 48개 후보 훈련·검증 → 후보 저장 → 이후 기간 평가.
2. `python main.py --test adaptive-robust`: 최근 훈련 63일·검증 21일로 조건을 고르고 다음 21일에 적용.
3. `python main.py --test unit-research`: 합성 자료로 공동 자금·미래 가격 차단·손절·비용 영향을 자동 검증.
4. `python main.py --test long-history`: 같은 48개 규칙·선택 방식으로 2020년부터 최근까지 연도별 평가.

장기 수집 범위는 `../Config/long-history.json`, 결과는 `../Data/tests/results/long-history`에 저장한다.
2020년 종목군에서는 Arm·Sony를 예열 자료 부족, SpaceX를 짧은 상장 이력, GOOG를 동일 회사 중복으로 제외한다.
2024-10-01 이후 종목군에는 Arm·Sony를 포함한다. 두 종목군의 수익은 서로 다른 포트폴리오로 해석한다.
연간 수익은 직전 연말 계좌 가치를 기준으로 계산하며 매년 자금을 초기화하지 않는다.

`python main.py --test` 메뉴에서도 선택한다. 13번 `adaptive`는 엄격 선택 전 비교용,
15번 `defensive`는 실제 인버스 ETF를 포함한 실패 가설 비교용이다. 최신 후보는 인버스를 사용하지 않는다.
연구 결과는 `../Data/tests/results/portfolio`, `adaptive-robust`의 실행별 폴더와 `latest.json`에 남는다.

## 수정 위치

- 종목: `../Config/peers.json`. GOOG는 GOOGL 중복으로 제외, SpaceX는 예열 자료 부족으로 제외.
- 기간·페이지·수집 간격·비용 스프레드: `../Config/portfolio-research.json`.
- 모멘텀·반등 가설 및 최소 5일 보유: `research/portfolio.py`의 `candidate_rules`, `reversal_rules`.
- 순차 선정 기준: 같은 파일의 `simulate_walk_forward`.
- 수수료·자금: `../Config/paper.json`. 실제 역사 요율 대신 명시한 가정이다.

`adaptive-robust`는 직전 포트폴리오 실행의 기간·종목을 재사용한다. 설정 변경 후에는 포트폴리오 연구부터 다시 실행한다.
가설은 모멘텀 24개와 추세 속 눌림·과매도 반등 24개다. 결과를 보고 종목을 빼지 않는다.
순위가 바뀌어도 최소 5일 전에는 교체하지 않으며, 손절·구간 말 청산에는 이 제한을 적용하지 않는다.

## 비용 스트레스 해석

1. 비용을 두 배로 올려 후보 선정까지 재수행한다. 선택 규칙이 바뀔 수 있다.
2. 후보 선택을 고정하고 비용만 올려 재생한다. 매수가 연동 손절·정수 수량 때문에 거래 경로가 바뀔 수 있다.
3. 거래 날짜·수량까지 고정하고 비용만 올린다. 순수 비용 민감도이며 재운용 시 현금·수량 재산정을 대신하지 않는다.

수정주가 연구 단위는 실제 주문 수량이 아니다. 배당·분사 보정 방식은 독립 검증되지 않았다.
현재 종목군을 과거에 적용한 생존·선정 편향, 공통 거래일의 누락 영향, 실제 호가·체결·역사 세금이 남는다.
이번 흑자는 같은 시험 구간을 반복해서 사용한 탐색이며 새 기간의 증거가 아니다.
기존 장중 뉴스 규칙에 자동 적용하지 않는다.

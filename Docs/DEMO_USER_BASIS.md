
`--execute`가 없으면 조회 전용이다. `--execute`는 기존 시험 진입점에서 이번 프로세스에만 적용되며 Config의 enabled/new_orders_allowed는 false로 유지한다.

프로그램은 별도 시세 관측을 시작하고 30종목 각각10분 이상·전체3회 이상의 현재 정규장 관측을 확인한다(약10~15분, 최대17분30초 대기). 확인 뒤 최신 모의계좌 잔고·전체 주문 이력·미체결·여력과 위험 원장을 다시 대조한다. 기존 운영 서비스는 시작하거나 재시작하지 않는다.

이 시험은 비어 있는 계좌의 최초 체결 전 범위에 한정한다. 기존 보유·미확인 주문·자금 변동·대출/매도대금 재사용·중지 상태·조회 누락·오래된 자료가 있으면 차단한다. 재시작 후 저장된 승인만으로 전송 자격이 살아나지 않는다. AAPL 지정가1주, 동시1주, 비용 예약을 포함한 총매수500 USD, 매수 시도최대2회, 매도/취소각2회, 활성10분이다. 첫 체결 후 추가 매수는 중지하고 확인된 수량의 매도·취소만 수행한다.

체결 전 비용은 기존1.003배 예약을 적용한다. 최종 비용 미확정은 0으로 확정하지 않는다. 실제 체결 뒤 비용/현금 대조가 미완료면 계좌가 비었어도 `review_required`로 남는다. 실제 최종 비용 경로와 실현 손익 검증은 별도 미완료다.

## 결과와 중단

# PyTrading 금지 목록

사용자 요청: 2026-10-30. 이 문서는 PyTrading 프로젝트의 금지 정책 기준 문서다. 구현·운영·검토 및 다른 AI에게 전달하는 작업 프롬프트에 적용한다.

## 거래·상품 금지

1. **대출 및 차입 거래 금지**
   - 대출, 신용융자, 주식담보대출, 미수거래, 대주, 차입 공매도를 사용하지 않는다.
   - 관련 API를 추가·복원하거나 현금주문 등의 공용 API 옵션으로 우회하지 않는다.
2. **선물 관련 상품 및 기존 금지 파생상품 금지**
   - 국내외 선물 직접 거래와 선물에 투자하거나 선물 성과를 추종하는 상품을 금지한다.
   - 선물 기반 ETF 및 선물 기반 레버리지·인버스 ETF도 금지한다. ETF라는 분류만으로 허용하지 않는다.
   - 기존 옵션·ELW 금지를 유지한다. 기존 선물·옵션·ELW 코드와 합성 검사는 보존하되 운영 활성화·주문·실시간 구독은 차단한다.
3. **통합증거금 금지**
   - 통합 여력 및 사후 자동환전을 사용하는 매수를 금지한다. 가입 여부 자체는 검사하지 않는다.
   - 통합증거금을 통한 원화·타 통화·매도대금의 교차 사용과 사후 자동환전을 전제로 주문하지 않는다.
   - 필요한 환전을 주문 전에 완료하고, 수수료 등을 고려한 해당 거래통화의 사용 가능한 보유 현금 범위에서만 주문한다.
4. **ETN 및 상품 종류 미확인 종목 금지**
   - 기존 주식·채권·ETF 허용 범위를 유지하되, 위 금지 조건에 해당하는 상품은 제외한다.
   - ETN과 상품 종류를 확인하지 못한 종목은 거래하지 않는다.

## 기존 운영 제한 유지

- FMP를 사용하거나 다른 유료 데이터 제공원으로 자동 대체하지 않는다.
- 제공 종료로 삭제한 국내 재무 API 7종을 복원하지 않는다.
- 실계좌 주문은 승인되지 않았다. 모의투자 작업으로 실계좌 전송을 허용하지 않는다.
- 부팅 자동 시작은 disabled로 유지하며, 사용자의 별도 요청 없이 활성화하지 않는다.
- 기존 매수 중지와 위험 한도를 임의로 해제·완화하지 않는다.
- 기존 Data·Credentials·계좌·대기 계획과 미커밋 변경을 보존한다.

## 적용 범위와 상태

- 위 거래·상품 금지는 모의투자와 실투자 모두에 적용한다. 시험 편의를 위해 예외를 만들지 않는다.
- 이후 다른 AI에게 전달하는 작업 프롬프트에 이 정책을 포함한다.
- 이 문서는 정책 기록이다. 프로그램 차단 기능의 구현·검증 완료를 뜻하지 않는다.

프로젝트 작업 지침: [AGENTS.md](../AGENTS.md). 개인 운영 메모는 이 문서의 위치를 참조하며, 정책 변경은 프로젝트 문서에 반영한다.

## KODEX 200 종목 한정 예외 (사용자 요청 2026-11-01)

KODEX 200(069500)은 사용자가 명시적으로 허용했다. 선물 사용 여부의 근거 미확인 조건에 대한 종목 한정 예외이며, 선물 미사용이 확인됐다는 뜻은 아니다. Config의 futures_based=null과 futures_review.status=unknown은 그대로 보존하고 policy_exception에 사용자 요청·날짜·범위를 별도 기록한다. 이 예외를 다른 ETF/ETN으로 확대하지 않는다. 선물 기반으로 확정된 상품의 차단과 통합증거금·대출·주문 승인 제한은 유지한다. 허용 목록 변경은 실제 주문 실행이나 기본 관찰 대상 추가를 뜻하지 않는다.


## 가입 상태 검사 제거 (사용자 요청 2026-11-01, 최신 정책)

통합증거금 가입·미가입 상태값은 조회하거나 신규 매수 자격으로 요구하지 않는다.
과거 unknown/cash_only 설정은 USD 전용 사용 정책의 호환값이며 계좌 상태 인증값이 아니다.
통합 여력 필드 선택(integrated)은 거절한다. 매수는 API 외화 주문가능액과 비용·전체
미체결 예약을 고려한 USD 현금 상한을 모두 지켜야 한다. API 여력에 이미 반영된 원격
예약은 API 여력에서 재차 차감하지 않는다. 현금 기준에서는 원격/로컬 예약을 한 번씩 확보한다.
가입 상태를 확인하지 않았다는 사실을 그대로 표시한다. 계좌 설정은 자동 변경하지 않는다.
기존 위험·비용·자금 변동 검증, 주문 차단, 상품 제한과 운영 중지는 별개로 유지한다.


## 한정 모의시험의 사용자 기준 허용 (2026-11-02)

사용자가 명시적으로 선택한 "한정 모의시험 기준으로 진행"을 적용한다. 기존100000 USD를 사용자 지정 현금 기준으로 보존하고 실제 최신 외화 여력·빈 보유·빈 체결·미체결 대조를 결합한다. 공식 현금/NAV 또는 과거 자금 이력을 검증했다고 표시하지 않는다. 일반/실계좌 위험 승인과 구분한 user_designated_demo_trial 근거이며, 500 USD·1주·최대2회 BUY의 기존 한도는 유지한다. 첫 체결 후 추가 매수는 차단하고 확인된 자기 보유 정리·취소만 허용한다. 이 선택은 실제 주문 자동 실행/실계좌 허가/부팅 활성화가 아니다. 원장/정책/계좌가 바뀌거나 재시작/만료하면 재조회한다. 기존 손실/복원/수동 중지는 면제하지 않는다.

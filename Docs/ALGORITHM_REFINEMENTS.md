# 알고리즘을 한 항목씩 조정하는 실험

CMD에서 실행합니다.

```cmd
cd /d C:\Projects\PyTrading
python Code\main.py --test refinements
```

기능 메뉴인 `python Code/main.py --test`에서도 소폭 조정 비교를 선택할 수 있습니다.
자동 검증은 `--test unit-refinements`, 전체 자동 검증은 `--test all`입니다.
기존 알고리즘 비교 `--test algorithms`와 현재 운용 엔진 재생 `--test engine-backtest`도 유지합니다.

## 무엇을 바꾸는가

`Config/algorithm-refinements.json`에 기준값 주변의 변경값을 적습니다.
각 후보는 기준 전략에서 **정확히 한 항목**만 바꿉니다. 모든 값의 조합을 전수 탐색하지 않습니다.

|계열|기준|비교할 변경|
|---|---|---|
|돌파|이전 55일 고점·20일 저점|고점 기간 40/70, 저점 기간 15/25|
|이동평균 추세|MA50·MA200|단기 40/60, 장기 150/250|
|위 두 계열의 위험|손절 2.5 ATR·추적 3 ATR|손절 2/3, 추적 2.5/3.5|
|위 두 계열의 보유|최대 126거래일|84/168거래일|
|모멘텀 회전|5거래일 회전·126거래일 보유|회전 10/21, 보유 84/168|
|저변동성 추세|21거래일 회전·126거래일 보유|회전 10/42, 보유 84/168|
|모든 계열|시장 필터 켬|필터 끔|

돌파 12개·추세 12개·회전 두 계열 각각 6개로 총 36개입니다.
세 기간(개발·검증·이후 평가)과 두 비용 조건에서 216회 재생합니다.
기간·공통 위험 예산은 `Config/algorithm-study.json`, 초기 현금·매매 비용은 `Config/paper.json`을 읽습니다.
변경값을 넣지 않으면 예전 12개 알고리즘의 기본 동작을 유지합니다.

## 후보를 어떻게 고르는가

개발·검증 결과만 사용합니다. 이후 평가를 계산하기 전에 `selection-before-evaluation.json`을 저장합니다.

- 개발 구간 기본 비용·비용 두 배 수익이 모두 양수.
- 검증 구간 기본 비용·비용 두 배 수익이 모두 양수.
- 검증 완료 거래 30건 이상, 기본 비용 PF≥1.1, 비용 두 배 PF>1.
- 기본·두 배 비용의 검증 최대 낙폭 각각 8% 이하, 검증의 두 연도 수익 모두 양수.
- 같은 계열에서 검증 비용 두 배 수익이 양수인 후보 비율 75% 이상.
- 적격 후보 중 검증의 **비용 두 배 수익률−2×최대 낙폭**이 가장 큰 것을 선택.
- 적격 후보가 없으면 현금 대기. 이후 결과가 더 좋았던 후보로 자동 교체하지 않음.

계열 내 양수 비율은 서로 독립된 통계 표본이나 성공 확률이 아닙니다.
근처 값을 조금 바꿔도 결과가 유지되는지 보는 설명적 지표입니다.
이 기준은 이전 후보의 이후 비용 스트레스 실패를 참고해 새 실험 전에 정했습니다.

## 어떤 기록이 남는가

- `Docs/RESEARCH_LOG.md`: 누적 연구 일지.
- `Data/research/experiments/registry.jsonl`: 가설 선언·개별 시작·완료·실패·평가 전 선정.
- `Data/tests/results/refinements/실행시각/`: 실행별 소스·자료 해시·조건·거래·곡선·비용·종목 기여.
- `Data/reports/refinements/report.md`: 최신 소폭 조정 보고서.
- `performance.png`: 이전 기준 전략과 사전 선정 후보의 이후 성과.
- `robustness.png`: 36개 전부의 수익률·최대 낙폭을 기본·두 배 비용으로 비교.
- `sensitivity.png`: 각 변경이 이후 수익률에 준 차이. 단위는 %포인트.
- `baseline-controls.json`: 시세·비용·기간이 같을 때 이전 실험 기본값의 전체 결과와 일치하는지 검사.
- `validation.json`: 완료 거래 비용·종목별 손익·현금·보유 한도 검산.

새로운 실행은 별도 폴더에 저장합니다. 이전 실험은 덮어쓰지 않습니다.
모든 후보를 남기므로 나중에 수익이 좋았던 후보만 골라 남기는 것을 방지합니다.

## 해석할 때

이번 연구 범위를 고르는 데 이전의 2025~2026년 결과가 영향을 줬습니다.
선정 함수가 이후 평가를 직접 읽지 않더라도 **전체 연구 과정에서 평가 자료를 재사용한 탐색**입니다.
새로운 독립 검증으로 주장할 수 없습니다. 향후 새 기간의 모의 운용이 필요합니다.

현재 지정한 종목을 과거에 소급한 편향, 수정주가의 가상 정수 수량, 배당·실제 호가·세금·현금 이자
미반영의 한계도 유지됩니다. 일봉 MDD는 종가 평가라 장중 손실보다 작게 나올 수 있습니다.
이 기능은 연구용이며 실제 주문·기존 모의 계좌·정상 실행의 매매 조건을 변경하지 않습니다.

이 문서의 장비 이름, 사용자명 및 절대 경로는 공개용 예시다. 실제 환경에서는 로컬 값을 사용한다.

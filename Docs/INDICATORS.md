# 경제·시장 지표 연구

프로젝트 폴더에서 `python main.py --test indicators`로 실행한다.
`python main.py --test`의 9번에서도 실행할 수 있다. 기존 지속 실행은 먼저 종료한다.
토스 시세 조회·Cboe 공개 CSV 수집이 필요하며 실제 주문은 없다.

| 자료 | 의미 | 연구 조건 |
| --- | --- | --- |
| 코스피 / SPY | 한국 시장 지수 / 미국 S&P 500 ETF 대용치 | 최근 종가가 50관측일 평균 초과 |
| VIX | 미국 옵션에서 계산한 기대 변동성 | 25 이하 |
| 한국 3년 국채 수익률 | 금리 상승 압력 | 20관측일 상승이 0.25%p 이하, 한국만 비교 |

조건은 `../Config/indicators.json`, 계산은 `research/indicators.py`, 수집·비교·보고서는
`tools/research_indicators.py`에 있다. 단위는 금리 수준 %, 변화 %p, 비중은 소수 비율이다.
0.25%p는 예를 들어 3.00%에서 3.25%로 오른 차이다.

지표 날짜를 신호 날짜보다 최소 2일 앞선 것만 사용한다. 한국 장중에 아직 끝나지 않은
미국 당일 종가를 사용하는 것을 피하기 위한 보수적 가정이다. 마지막 관측이 7일보다 오래됐거나
평균 계산 표본이 부족하면 신규 매수를 보류한다. 기존 보유의 손절은 계속 작동한다.
장중 전략에 바로 적용하지 않고 일봉 연구에서 효과를 먼저 비교한다.

종목 규칙은 기존 24개 후보에서 훈련·검증으로 선정하고 고정한다.
기본 규칙, 시장 조건, VIX 조건, 두 조건 동시 적용, 한국 금리 조건을 각각 비교한다.
지표 선택도 검증 기간에서만 하며 시험 결과를 본 뒤 임계값을 바꾸지 않는다.
과거 원자료는 `../Data/history/indicators`, 실행별 보고서·그래프·코드 사본·고정 후보는
`../Data/tests/results/indicators/날짜-시각`, 최신 경로는 같은 폴더의 `latest.json`이다.

2026-10-11 실행에서는 추가 조건이 삼성전자·애플의 시험 진입을 차단하지 않아
수익·거래가 기존 결과와 같았다. 삼성전자 +0.1571%/4거래, 애플 +0.4508%/2거래로
표본 부족이며 단순 보유에도 못 미쳤다. 금리·변동성을 넣으면 반드시 좋아진다는 근거는 없었다.
이 기간은 이미 확인한 시험 자료이므로 탐색 결과로 남기며 독립 검증 통과로 취급하지 않는다.

GDP·CPI·고용 등은 당시 발표값과 발표 시각이 필요하다. 현재 수정된 수치를 과거 시점에
소급 적용하지 않는다. [ALFRED](https://alfred.stlouisfed.org/)는 과거 발표 빈티지 자료를 제공한다.
현재 VIX CSV·토스 지표는 최신 배포 이력이므로 과거 수정 이력과 실제 배포 지연은 미검증이다.
2일 지연만으로 이 문제가 해결됐다고 주장하지 않는다.

합성 입력 동작 검사는 `python main.py --test unit-research`로 수행한다.
그래프가 필요하면 `python -m pip install matplotlib`로 설치한다. 기본 지속 실행은 표준 라이브러리만 필요하다.

# 실제 과거 데이터로 규칙 비교

```cmd
python main.py --test backtest
```

처음에는 ../Config/settings.json의 인증 파일·종목 설정으로 토스 과거 1분봉을 읽는다.
주문·계좌 조회는 없다. 같은 인증키를 쓰는 지속 실행은 먼저 종료한다.
기존 실행 폴더의 OS 잠금이 잡혀 있으면 과거 데이터 수집을 중단한다.
완료된 과거 자료가 있으면 재사용하고 인증 파일도 읽지 않는다.
수집 도중 중단되면 저장된 페이지부터 이어간다. 새 자료가 필요하면 해당 캐시 파일을
다른 이름으로 보관한 뒤 실행한다. 최종 시험에 썼던 가격을 새 시험으로 간주하지 않는다.

## 연구와 실시간 매매의 관계

현재 실시간 전략은 확인된 뉴스가 있어야 진입한다. 과거에 확인된 사건과 당시 수신 시각의
자료가 아직 없으므로 이 연구는 **가격·거래량만 쓰는 별도 규칙 비교**다.
연구 결과를 실시간 전략 설정에 자동 적용하지 않는다.
1차 당일 청산 12개/종목, 2차 보유 방식 추가 24개/종목을 비교했고 손실도 저장한다.
훈련 결과 상위 3개만 검증 기간에서 비교하고 그중 1개를 고정해 최종 기간에 시험한다.
돌파·반등·평균 회귀 가설이며 매일 장중에 판단한다. 보유 방식은 당일 청산 또는 최대 5세션이다.

## 데이터·체결 가정

- 최근 120일, 종목당 최대 600페이지(페이지당 최대 200분봉). 제한은 ../Config/research.json에서 수정한다.
- 분봉 5개를 완성된 5분봉으로 합치며 정규장에 분봉이 모두 있는 세션만 사용한다.
- KR 09:00~15:20, US 현지 09:30~16:00. 미국 DST 시각 변환은 2007년 이후 규칙을 쓴다.
- 휴장·조기 종료일의 공식 역사 달력은 연결하지 않았다. 부분 세션은 제외되며 선택 편향이 생길 수 있다.
- 종목별 독립 가상 계좌, 초기 자금의 10% 예산. 여러 종목을 하나의 계좌로 묶는 연구는 아니다.
- 신호는 완성된 봉으로 계산하고 다음 봉 시가에 스프레드·슬리피지를 불리하게 적용한다.
- 매수 0.1%, 매도 0.2%, 슬리피지 편도 0.1%는 ../Config/paper.json의 가정이다. 실제 토스 요율·세금이 아니다.
- 스프레드 편도 0.05%도 가정이다. 실제 과거 호가·잔량이 없다.
- 갭 하락 손절은 손절가와 시가 중 낮은 가격. 현재 봉 고가로 높아진 추적 손절은 다음 봉부터 적용한다.
- 당일 청산 후보는 마지막 봉에서 청산한다. 다음 날 보유 후보는 손절·보유 기한 또는 표본 종료 때 청산한다.
- 실제 주문 대기·부분 체결·배당·기업행동은 미재현이다.

## 수정과 통과 기준

시간순 60% 훈련 / 20% 검증 / 20% 최종 시험. 각 구간은 새 가상 자금으로 시작한다.
모든 후보의 훈련 결과를 기록하며, 선택은 훈련·검증에만 의존한다.
최종 시험 가격을 바꿔도 선택되는 규칙이 바뀌지 않는지 자동 테스트한다.

연구 후보 통과 조건은 60세션 이상, 훈련·검증·시험 모두 순수익 양수,
시험에서 같은 투자 비중의 단순 보유 초과, 시험 완료 거래 30건 이상,
시험 최대 낙폭 5% 이하, 비용·슬리피지·스프레드 두 배에서도 양수다.
한 조건이라도 실패하면 rejected다. 후보 비교 자체의 과최적화 위험은 남는다.

같은 원자료를 다른 계산 코드·설정으로 다시 시험하면 `holdout_reused=true`와
`exploratory_holdout_reused`로 기록한다. 한 번 본 최종 시험을 반복해 양수를 만들더라도
미사용 데이터의 수익성 검증으로 취급하지 않는다. 다음 검증에는 새로운 기간이 필요하다.

그래프는 선택적 matplotlib를 사용한다. 시세 수집·모의 계산은 표준 라이브러리만 쓴다.
`python main.py --test unit-research`는 실제 API 없이 다음 봉 체결·비용·갭 손절·기간 분리·페이지 중복을 검증한다.

수익률 그래프는 실제 가격으로 계산한 모의 결과이며 실제 계좌 성과가 아니다.
후보 통과도 뉴스 전략의 검증이나 미래 수익 보장이 아니다.

# 알고리즘 실험과 누적 기록

CMD에서 실행합니다. 저장한 일봉만 사용하며 인증·실제 주문·운용 계좌 변경은 없습니다.

```cmd
cd /d C:\Projects\PyTrading
python Code\main.py --test algorithms
```

`python Code/main.py --test` 메뉴에서도 알고리즘 비교를 선택할 수 있습니다.
자동 검증은 `python Code/main.py --test unit-algorithms`, 전체 검증은 `--test all`입니다.

## 어디에 무엇을 기록하는가

- `Docs/RESEARCH_LOG.md`: 사람이 읽는 누적 일지. 실험 목적·기준·결과·한계·다음 과제를 추가 기록합니다.
- `Data/research/experiments/registry.jsonl`: 가설 선언, 개별 실험 시작·완료·실패, 평가 전 후보 선정, 전체 완료를 시간순으로 추가합니다.
- `Data/tests/results/algorithms/실행시각/`: 실행마다 새 폴더. 이전 결과를 덮어쓰지 않습니다.
- `Data/reports/algorithms/report.md`: 가장 최근 비교 보고서. 같은 폴더에 성과 그래프와 비용 비교 그래프가 있습니다.
- `declaration.json`: 실행 전에 고정한 조건·원본 SHA-256·코드 해시·자료 범위.
- `source/`: 실행 당시 Python 소스 사본.
- `알고리즘-기간-비용.json`: 거래·다음 날 계획·매일 계좌 평가·진단·최종 보유.
- `analysis.json`: 완료 거래 가격 손익·스프레드·슬리피지·수수료, 종목별 실현·미실현 손익, 매도 사유, 검산 결과.
- `selection-before-evaluation.json`: 이후 평가를 계산하기 전에 확정한 후보.
- `summaries.json`: 모든 알고리즘의 기간·비용별 성과. 탈락 후보도 보존합니다.

재실행은 자동으로 이전 실험을 수정하거나 더 좋은 임계값을 고르지 않습니다.
새 가설은 설정·코드를 수정하고 새 실행으로 남깁니다. 실행 전 설정을 선언하고 결과에 따른
수정 이유를 일지에 적어야 합니다. 이미 본 평가 기간을 다시 사용하면 그 사실을 기록합니다.

## 수정할 위치

- 종목: `Config/settings.json`의 `symbols`. 현재 미국 30종목 공동 USD 계좌입니다.
- 기간·비용 스트레스·위험·선정 기준: `Config/algorithm-study.json`.
- 초기 현금·최대 동시 보유·종목별 비중·기본 비용: `Config/paper.json`.
- 6종류의 진입·매도·순위 조건: `Code/research/algorithm_study.py`의 `signal()`.
- 회전 주기·보유 한도·체결 순서: 같은 파일의 `replay()`.
- 후보 선택: `Code/tools/run_algorithm_study.py`의 `choose_candidate()`.

현재 6종류 × 시장 필터 유무 = 12개 가설입니다. 개발(2020~2022), 검증(2023~2024),
이후 평가(2025~자료 종료)의 3기간 × 기본·두 배 비용으로 총 72회 실행합니다.
개별 구간은 같은 초기 현금으로 새로 시작하므로 구간 수익률을 더해 전체 수익률이라고 하면 안 됩니다.

모든 종목은 관측 일봉 201개 이후부터 진입합니다. 신규 상장 때문에 전체 기간을 줄이지 않습니다.
수집 오류로 격리한 일봉은 복원하지 않습니다. 누락 보유 시세는 이전 평가를 유지하고 진단 횟수를 남깁니다.
SPY 200일선 필터는 신호일 종가에 확인하고 다음 날 주문에 적용합니다.
현재 조건은 연구용이며 정상 실행 `python Code/main.py`의 운용 전략으로 연결되지 않습니다.

## 해석

이전 5분봉 엔진 검증과 주기·손절·자료 범위가 다르므로 수익률만 비교할 수 없습니다.
수정주가와 가상 정수 수량, 현재 종목 소급 선택, 과거 자료 재사용, 배당·실제 호가·세금 미반영을
명시합니다. 일봉 최대 낙폭은 장중 손실보다 작게 나올 수 있습니다.
과거 성과가 양수여도 이후 평가·비용 스트레스가 약하면 실전 전환 후보로 확정하지 않습니다.

이 문서의 장비 이름, 사용자명 및 절대 경로는 공개용 예시다. 실제 환경에서는 로컬 값을 사용한다.

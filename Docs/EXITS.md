# 원가·이익 보호 매도

`python main.py`의 장중 판단·모의 계좌에 적용한다. `../Config/strategy.json`에서 비율을 수정하고 재시작한다.
실제 주문 기능은 없으며 손실 전에 팔 수 있다는 보장은 없다.

| 설정 | 기본값 | 역할 |
| --- | ---: | --- |
| stop_loss | 0.03 | 원가보다 3% 하락하면 손절 |
| trailing_stop | 0.04 | 관찰한 고점보다 4% 하락하면 추적 손절 |
| breakeven_trigger | 0.03 | 비용 차감 고점 수익 3%부터 원가 보호 활성화. 0은 비활성 |
| exit_profit_buffer | 0.002 | 원가 보호 가격은 비용 차감 순수익 0.2%를 목표로 계산 |
| profit_lock_trigger | 0.05 | 비용 차감 고점 수익 5%부터 이익 보호 활성화. 0은 비활성 |
| profit_keep_ratio | 0.5 | 고점 순이익의 50%에 해당하는 가격을 매도 기준으로 설정 |
| exit_sell_cost_ratio | 0.003 | 직접 판단 입력에 비용 정보가 없을 때의 매도 비용 가정 |

매입 원가가 100이고 고점에서 비용 차감 수익이 10%라면, 이익 보호는 비용 차감 수익 5%에 해당하는 호가를 기준으로 한다.
기존 추적 손절이 더 높은 가격이면 기존 조건을 유지한다. 가격 보호 조건을 전부 끄려면 두 trigger를 0으로 설정한다.

모의 계좌 원가는 매수 수수료·슬리피지를 포함한다. 보호 가격에는 `../Config/paper.json`의 매도 수수료와 슬리피지도 반영한다.
최고 매수 호가는 유효한 시세에서만 갱신하며 저장·재시작 후에도 유지한다. 잘못된 뉴스나 부족한 봉 때문에 가격 보호를 건너뛰지 않는다.
매도 이유는 `breakeven_protection`, `profit_lock`, `trailing_stop`, `stop_loss`로 기록한다.
새로운 가격 보호를 통과하면 기존 확정 악재·완성 봉 평균가격 이탈 조건도 검사한다.

보호가 켜지기 전 매수 직후 하락에는 기존 손절이 적용된다. 갭 하락·60초 조회 사이 급락·시세 장애·체결 지연에서는 손실이 발생할 수 있다.
기준 가격에 도달했다는 신호이며 거래소에 접수한 예약 주문이 아니다. 모의 체결도 실제 체결을 보장하지 않는다.

```cmd
python main.py --test unit-strategy
python main.py --test unit-paper
python main.py --test exits
```

exits는 이미 저장된 실제 장기 일봉으로 기준/원가 보호/이익 보호/둘 다를 비교한다.
기존 장기 선택 규칙·날짜·현금 대기 구간을 고정하며 기준 결과 재현 실패 시 중단한다.
당일 고가로 같은 날 손절 가격을 올리지 않고 다음 날부터 반영해 일봉 안의 고가·저가 순서를 추정하지 않는다.
갭 하락은 기준가와 시가 중 낮은 가격에 매도 비용을 적용한다. 최소 보유 기간은 보호 매도를 막지 않는다.
선언·소스 사본·시세 해시·거래 내역·비용 두 배 결과·보고서·그래프를 `../Data/tests/results/exits/날짜-시각`에 저장한다.
장기 자료가 없으면 먼저 `python main.py --test long-history`를 실행한다. 그래프에는 matplotlib 설치가 필요하다.

일봉 연구와 실시간 5분봉 엔진의 진입·손절 폭은 다르다. 과거 일봉 성과를 장중 수익성으로 해석하지 않는다.
이번 조건은 위험 보호 기능이며 전 구간 수익률 개선이 확인된 전략이 아니다. 실제 장중 모의 기록으로 별도 평가해야 한다.

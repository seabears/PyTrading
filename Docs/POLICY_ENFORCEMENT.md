# 금지 정책의 코드 적용과 검증

재개 확인일: 2026-11-01 KST. 정책과 과거 조사 자료는 2026-10-30 작업에서 이어받았다. 금지 목록의 구현이며 매매 허가가 아니다. 실제 조회·주문·계좌 설정 변경·운영 배포를 하지 않는다.

## 통합증거금

`cash_service_policy.py`는 USD 전용 사용 정책을 검사한다. 사용자 요청(2026-11-01)에 따라 통합증거금 가입·미가입 상태값과 이를 증명할 공식 파서를 더 이상 요구하지 않는다. unknown/cash_only 설정에서 모두 외화 주문가능액 `ovrs_ord_psbl_amt`를 사용하며 integrated 설정과 통합 여력 필드 선택은 거절한다. 설정이나 숫자가 계좌 미가입을 인증한다는 뜻은 아니다.

신규 주문 생성과 KIS 전송 직전에는 기존 계좌·조회 시각·위험 체크포인트를 검사한 뒤 `require_usd_funding`으로 비용 완충1.003 및 모든 매수 예약을 포함한 USD 현금 상한을 검사한다. API 여력 계산에서는 이미 대조된 원격 예약을 다시 빼지 않는다. USD 현금 계산에서는 전체 예약을 한 번씩 확보한다. 가입 상태가 아닌 자금 범위로 제한한다. 원주문·보유가 확인된 위험 축소 매도·취소 경로는 기존대로 유지하며 계좌 설정을 변경하지 않는다.

KIS 관리 전송은 부울 허가만으로 열리지 않는다. 요청과 원장 문맥을 재검사하고 HTTP 간격 대기 후에도 다시 검사한다. prod 전송·대출 옵션·미확인 상품·ETN·불허 파생상품 차단을 유지한다.

## 등록 ETF 검토

ETF는 futures_based=False 하나만으로 허용하지 않는다. 종목에 연결된 non_futures 판정·확인일·공식 발행사 자료 URL·보관 원본 SHA256·판정 이유가 필요하다. 선물 기반·선물 기반 레버리지/인버스·선물 여부 미확인은 차단한다. 새 종목 이름만으로 판정하지 않는다.

| 등록 종목 | 판정 | 근거와 한계 | 동작 |
|---|---|---|---|
| SPY | non_futures | State Street 공식 제공 투자설명서 Investment Restrictions의 선물·옵션·스왑 등 파생상품 투자 금지. 2026-10-30 확인, 제공본의 제한 조항을 근거로 사용하며 최신 미국판 전체를 새로 대조했다는 뜻은 아님 | 허용 유지 |
| 069500 | unknown | 삼성자산운용 공식 상품 개요로 KOSPI200 주식지수 추종은 확인. 선물 사용을 배제하는 명시적 제한/완전한 운용 근거가 부족함 | 2026-11-01 사용자 지정 예외로 허용. 선물 미사용 확인은 아님 |

공식 원문: SPY https://www.ssga.com/library-content/products/fund-docs/etfs/apac/prospectus-sg-en-spy.pdf ; KODEX200 https://www.samsungfund.com/etf/product/view.do?id=2ETF01 . Config/product-policy.json에 출처/해시/확인일을 저장했다. 새 보고서 product-sources/에 원본이 있다. 실제 등록된 선물 ETF를 확인했다고 주장하지 않으며 금지 사례는 합성으로 검사한다. 정상 주식 등록값과 허용 상품 종류(stock/bond/etf)는 변경하지 않는다.

## 남은 주문 시험 조건

사용자 확인 초기 가상 현금100000 USD는 감사 기준으로만 확인됐고 현재 USD 현금/NAV가 아니다. 과거 문의와 official-contracts.json은 재사용하며 같은 API를 다시 조사하지 않았다. 다음 자료를 한 번에 확보해야 한다.

| 자료 | 현재 판정 | 필요한 내용과 이유 |
|---|---|---|
| 초기 가상 현금 기준 | 확인됨(사용자 확인) | 재확인 요청 없음. 최초 기준 시점 이후 검증 범위를 정의할 때 별도로 사용 |
| 현재 USD 현금·NAV 명세 | 미확인 | 동일 모의계좌/통화/평가 시각, 체결·결제 기준 구분과 자산·예약 내역. 주문가능액을 복사하지 않음 |
| 통합증거금 가입 상태 | 검사 대상 제외(사용자 요청) | 미가입 증빙을 추가 요청하지 않음. 주문의 USD 현금·예약 상한 검사는 유지 |
| 향후 체결 비용·확정 시점 | 미확인 | 적용률·수수료/세금·정산 시점·개별 사건 식별자를 확인할 모의 지원 원본. 현재 빈 체결의 비용 해당 없음과 미래 비용0을 구분 |
| 입출금·배당·환전·수동 사건 | 미확인 | 기준 시점부터 전체 기간·통화·금액·ID·페이지 완전성이 있는 공식 내역. 없다는 가정 금지 |

과거 저장 공식 계약상 foreign-margin, inquire-paymt-stdr-balance, inquire-period-trans, inquire-period-profit 및 inquire-present-balance의 output2는 모의 미지원으로 확인됐다. 이는 특정 경로의 '공식 미지원'이며 모든 대체 API/HTS/화면이 미지원이라는 뜻이 아니다. 대체 경로는 미확인이다. 비용 전용 API 없음만으로 미래 비용을0으로 만들지 않는다. 기존 비용 예약 완충1.003과 위험 한도는 변경하지 않았다.

현재 가입 상태 확인 문의는 필요하지 않다. 비용·자금 변동 등 다른 위험 자료의 처리 상태는 후속 원장 연결 보고서와 구분한다. 과거 조사/문의 원본은 당시 이력으로 보존한다.

## 외부 호출 없는 검사

Windows CMD:

    cd /d C:\Projects\PyTrading
    %USERPROFILE%\AppData\Local\Programs\Python\Python312\python.exe Code/main.py --test all
    %USERPROFILE%\AppData\Local\Programs\Python\Python312\python.exe Code/main.py --test unit-api

전체 진입점은 socket 연결을 차단한다. 새 Test/broker/test_prohibited_policy.py는 금지 사례에서 urllib 전송 함수 호출 수를0으로 검증하며, 별도로 정상 GET과 기존 위험 축소/취소의 합성 회귀를 유지한다. 실제 API·체결 검증이 아니다.

ARM 재현은 tested-source.tar.gz를 새 격리 경로에만 풀고 기존 venv의 Python으로 `Code/main.py --test all`을 실행한다. 운영 Data/Credentials·서비스를 복사/교체하거나 enable하지 않는다. 인증이 필요 없는 검사다. 이번 ARM 실행 여부와 정확한 경로·결과는 최신 보고서 results.json을 기준으로 한다.

원본은 새 보고서 before-source.tar.gz에 보존했다. 롤백은 활성 서비스에 덮어쓰지 말고 별도 폴더에서 변경 파일을 대조한다. 운영 배포가 없어 운영 서비스 롤백은 필요 없다.

## KODEX 200 종목 한정 예외 (사용자 요청 2026-11-01)

KODEX 200(069500)은 사용자가 명시적으로 허용했다. 선물 사용 여부의 근거 미확인 조건에 대한 종목 한정 예외이며, 선물 미사용이 확인됐다는 뜻은 아니다. Config의 futures_based=null과 futures_review.status=unknown은 그대로 보존하고 policy_exception에 사용자 요청·날짜·범위를 별도 기록한다. 이 예외를 다른 ETF/ETN으로 확대하지 않는다. 선물 기반으로 확정된 상품의 차단과 통합증거금·대출·주문 승인 제한은 유지한다. 허용 목록 변경은 실제 주문 실행이나 기본 관찰 대상 추가를 뜻하지 않는다.

KODEX200 사용자 예외를 포함한 최종 소스로 Windows Python3.12.6와 실제 ARM aarch64/Python3.13.5에서 각각709개 전체 검사를 새로 실행해 통과했다. 금지 전송 검증은 각각46회/전송 호출0회. Code/Config/Test255파일을 실제 실행 전후와 전송 아카이브까지 대조해 일치했다. 이전 ARM 접속 실패 보고서는 당시 기록으로 보존한다. 최신 근거: [policy-completion20261101-175904](../Data/reports/policy-completion20261101-175904/report.md).

운영 서비스는 이번 읽기 전용 확인에서 inactive/dead, 부팅disabled였다. 시작·재시작·배포·enable·매수 중지 해제는 하지 않았다. 실제 API 조회/주문0건이며 계좌 현금/NAV·비용·자금 사건·통합증거금 미사용 근거는 여전히 미확인이다. 합성 검사 완료와 실제 주문 시험 완료를 구분한다.


## 가입 상태 검사 제거 (사용자 요청 2026-11-01, 최신 정책)

통합증거금 가입·미가입 상태값은 조회하거나 신규 매수 자격으로 요구하지 않는다.
과거 unknown/cash_only 설정은 USD 전용 사용 정책의 호환값이며 계좌 상태 인증값이 아니다.
통합 여력 필드 선택(integrated)은 거절한다. 매수는 API 외화 주문가능액과 비용·전체
미체결 예약을 고려한 USD 현금 상한을 모두 지켜야 한다. API 여력에 이미 반영된 원격
예약은 API 여력에서 재차 차감하지 않는다. 현금 기준에서는 원격/로컬 예약을 한 번씩 확보한다.
가입 상태를 확인하지 않았다는 사실을 그대로 표시한다. 계좌 설정은 자동 변경하지 않는다.
기존 위험·비용·자금 변동 검증, 주문 차단, 상품 제한과 운영 중지는 별개로 유지한다.

이 문서의 장비 이름, 사용자명 및 절대 경로는 공개용 예시다. 실제 환경에서는 로컬 값을 사용한다.

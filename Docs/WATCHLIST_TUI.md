# 관찰 목록 TUI

운영 TUI는 라즈베리파이의 Linux·SSH 터미널을 대상으로 관리한다. 추가 패키지 설치는 필요 없다. TUI는 관찰 목록·선정 조건의 설정 편집과 저장된 상태 조회 도구다. 인증·시세·계좌 API, 주문·취소, 서비스 시작·중지·재시작, 부팅 설정, 매수 중지 해제는 호출하지 않는다.

## 실행

Pi에서는 기존 설치 폴더에서 실제 사용하는 Linux 설정을 지정한다:

```sh
PYTRADING_SETTINGS="$PWD/Config/settings-linux.json" .venv/bin/python Code/tui.py
```

설치별 Linux 설정 경로가 다르면 기존 관찰 프로그램과 같은 `PYTRADING_SETTINGS`를 사용한다. 사용자 목록은 그 파일의 `symbols`를 편집한다. 기본 Windows 설정은 `Config/settings.json`이다. `PYTRADING_EXECUTION_CONFIG`를 사용하는 경우 같은 환경을 지정하면 해당 체결 방식의 계좌 투영을 관리 전용 화면에서 읽는다. TUI에서 체결 방식을 변경하지는 않는다.

Pi의 `~/CMD/watchlist.sh` 실행 파일도 제공한다. 코드가 반영된 설치 경로로 이동하고 Linux 설정을 선택한 뒤 TUI만 연다. 매매·시세 수집 서비스는 시작하지 않는다.

터미널은 가로 80칸 이상을 권장하며 100칸이면 조건 이름이 더 잘 보인다. 최소 가로 60칸·세로 16줄이다. ANSI 화면을 지원하지 않는 환경이나 파이프 입력에서는 줄 입력 명령으로 동작하고 입력 끝에서 종료한다.

## 화면

1. **사용자 지정**: 현재 설정 파일의 고정 관찰 종목. 자동 삭제 대상이 아니며 사용자가 직접 추가·삭제한다.
2. **자동 선정·대기**: 유효한 자동 선정과 수집 중/탈락 후보. 거래대금 근삿값, ATR, 실제 호가 표본 수, 판정 사유를 표시한다. 값이 없으면 `-`이며 0으로 채우지 않는다.
3. **추가·제외 이력**: 최근 80개 판정 스냅샷의 변경을 표시한다. 전체 원본은 `Data/universe/history`에 보존돼 있다. 현재 선택 결과에 변경이 없어도 이 범위 내의 앞선 제거 이력을 읽는다.
4. **관리 전용**: 현재 실행 설정에 해당하는 계좌 파일과 로컬 주문 원장을 기준으로, 신규 진입 목록에서 빠졌지만 보유·미체결·계획 관찰이 필요한 종목. 실제 증권사 계좌를 새로 조회한 결과가 아니다. 계좌 파일이 없으면 미확인으로 표시한다.
5. **선정 조건**: 가격·시총·거래대금·ATR·호가·종목 상한·조회 간격을 보고 수정한다. 기존 검증기의 최소 기준과 최대 한도를 그대로 적용한다.

화면은 2초마다 로컬 자료를 읽는다. 이때 시세·인증·계좌 조회를 호출하지 않는다. SQLite 주문 원장은 `mode=ro`, `query_only=ON`으로 읽고 매번 연결을 닫는다. 계좌 식별자·인증값·인증 파일 경로·원문 응답은 화면에 출력하지 않는다.

## 키

|키|기능|
|---|---|
|1~5 또는 좌우 방향키|화면 탭 이동|
|상하 방향키 또는 j/k|행 선택|
|n/p 또는 PageDown/PageUp|페이지 이동|
|Enter|선택 행 전체 내용 보기|
|r|로컬 화면 새로고침|
|a|확인된 미국 주식을 사용자 목록에 추가|
|d|사용자 탭의 선택 종목 삭제, y 확인 필요|
|t|자동 선정 켜기/끄기 저장, y 확인 필요|
|e|조건 탭의 선택 조건 수정|
|q, Esc, Ctrl+C|TUI 종료|

`d`는 사용자 목록에서만 삭제한다. 자동 선정에 포함되거나 기존 보유·미체결 관리 대상이면 관찰이 남을 수 있다. 자동 목록은 매일 조건으로 추가·제외하므로 이 화면에서 강제로 탈락시키거나 통과시키지 않는다.

`a`는 공식 상품 분류와 거래소가 이미 확인된 USD 주식만 허용한다. 자동 검색으로 확인된 종목도 사용자 지정으로 편입할 수 있다. 등록되지 않은 상품은 확인 자료를 준비해야 하며 티커 이름만 보고 허용하거나 TUI에서 상품 금지 정책을 변경하지 않는다. ETF/채권 편집 UI는 이번 범위에 넣지 않았으며 기존 허용 상품 정책 자체를 바꾸지 않는다.

조건의 ATR·호가 비율은 화면과 입력에서 **%**를 사용한다. 예를 들어 ATR `7`을 입력하면 기존 설정 파일에는 `0.07`로 저장한다. 금액은 USD, 간격은 초다.

## 저장과 반영

설정은 저장 직전 파일 해시를 대조한다. 다른 창에서 수정했으면 덮어쓰지 않고 새로고침을 요구한다. OS 편집 잠금과 원자적 저장을 사용하고 원본 한 세대는 `.previous`에 보존한다. 감사 이력은 `Data/watchlist-tui/audit`에 변경 항목만 남기며 인증 경로·설정 전체·계좌를 복사하지 않는다.

설정을 저장해도 TUI가 관찰 프로그램을 자동 재시작하지 않는다. **실행 중인 프로그램의 일관된 반영에는 정상 종료 후 재시작이 필요하다.** 기존 프로그램이 일부 신규 매수 자격을 즉시 재확인하더라도 전체 종목·수집기의 설정을 갱신했다는 뜻은 아니다. 설정 변경 직후 화면에서도 반영 시점을 안내한다.

감사 기록 준비가 실패하면 설정은 바꾸지 않는다. 설정 저장 후 감사 완료 기록만 실패한 경우에는 설정이 이미 저장됐다고 별도로 알린다. 저장 실패를 기존 계좌 초기화나 재시도로 우회하지 않는다.

TUI를 닫아도 별도로 실행 중인 관찰/매매 프로그램은 종료하지 않는다. 자동 목록 수집은 기존 프로그램이 실행 중일 때만 동작하며 TUI만 켜는 것으로 시작되지 않는다.

## 깜빡임 없는 갱신

파일은 2초마다 확인하되 표시 내용이 같으면 화면 출력은 하지 않는다. 바뀐 행만 커서 위치를 지정해 한 번에 전송하며 화면 전체 지우기는 보내지 않는다. 입력창 종료·창 크기 변경·r 강제 갱신 때도 전체 화면을 비우지 않고 필요한 행을 덮어쓴다. 업데이트 전에 열었던 TUI는 q로 닫고 ~/CMD/watchlist.sh로 다시 열어 새 코드를 적용한다. 별도 관찰/매매 서비스 재시작은 필요 없다.

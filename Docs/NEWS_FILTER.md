# 뉴스 선별 기준

뉴스는 `../Config/news-filter.json`의 출처·종목 이름·유효 기간과
`news/filtering.py`의 사건 규칙으로 선별한다. 실행 인자는 추가하지 않았다.

1. Google News RSS 검색에 허용 출처의 `site:` 조건을 넣어 검색 범위를 좁힌다.
2. RSS의 출처 도메인과 언론사 이름이 **모두** 설정 목록과 일치하는지 검사한다.
3. 제목에 대상 회사 이름 또는 종목 코드가 있는지 확인한다.
4. 시간대가 있는 발행 시각이 최근 24시간 안인지 검사한다.
5. 실적·가이던스, 계약, 자사주·배당, 증자·채무, 인수·합병, 규제·소송,
   생산 중단·리콜, 주문·생산량 변경, 부도·파산 사건을 제목에서 찾는다.
6. 추천·목표주가·가치평가, 추측·루머·검토·부인, 단순 지분율·보유 변동 보도를 제외한다.

허용 출처 목록은 사용자가 고칠 수 있는 초기 정책이다. 신뢰도 인증이나 진실 보증이 아니다.
국내는 연합뉴스·연합인포맥스·한국경제·매일경제·조선비즈·서울경제,
미국은 Reuters·Bloomberg·WSJ·FT로 시작한다. 원문 출처 정보가 없으면 제외한다.
중요한 사건이라도 목록 밖 출처, 제목 표현 차이, 회사 이름 누락 때문에 놓칠 수 있다.
지분 변동 기사도 가격에 영향을 줄 수 있지만, 현재 정책에서는 사건 중심 후보에서 제외한다.

## 직접 확인

```cmd
python main.py --test news
python main.py --test unit-news
```

수집 건수 → 선정 건수 / 제외 건수와 각 이유를 표시한다. 선정 0건도 정상 결과다.
Google RSS 검색은 제한된 결과를 반환하므로 전체 뉴스 수량을 뜻하지 않는다.

| 파일 | 내용 |
| --- | --- |
| ../Data/tests/results/live-news.json | 이번 테스트에서 선정된 후보만 저장 |
| ../Data/tests/results/live-news-report.json | 이번 테스트의 선정·제외 이유, 발행 시각, 전체 링크 |
| ../Data/paper/news-candidates.json | 지속 실행에서 선정한 후보 누적; 수집 시 기존 항목의 정책·유효 기간 재검사 |
| ../Data/paper/news-filter-시장-종목.json | 지속 실행의 종목별 최근 선별 보고서 |

본문과 원문 주소를 독립적으로 확인하지 않는다. RSS 메타데이터만 검사했으므로
`source_check`는 `rss_metadata_only`, `confirmed`와 `source_verified`는 항상 false다.
동일 사건의 서로 다른 기사는 아직 사건 단위로 통합하지 않는다.

## 매매에 쓰기 전

선정은 검토할 기사 찾기다. 기사 본문·공식 발표·규모·발표 시각·이미 반영된 가격을
확인하기 전에는 호재·악재나 매수·매도를 자동 확정하지 않는다.
이번 변경은 수집 후보를 줄이며 기존 수동 사건 등록 절차를 유지한다.
선별 사건 분류는 매매 엔진의 지원 사건 분류보다 넓다. 인수·생산 변경 등이 선정돼도
해당 사건을 곧바로 지원되는 긍정·부정 사건으로 바꿔 등록해서는 안 된다.

한국 [DART 주요사항보고서](https://opendart.fss.or.kr/guide/main.do?apiGrpCd=DS005),
미국 [SEC 8-K 설명](https://www.sec.gov/files/readan8k.pdf)에는 계약·자금조달·기업 변경 등
공식 사건을 확인하는 자료가 있다. 공시·회사 IR의 직접 수집·대조는 아직 구현하지 않았다.
뉴스 제목 규칙 테스트와 실제 RSS 연결 확인은 수익성·주가 영향 예측 정확도를 증명하지 않는다.

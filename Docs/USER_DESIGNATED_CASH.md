# 사용자 지정 모의 현금 연결

사용자가 100000 USD를 현금 계산 기준으로 사용하도록 명시했다. Config/kis-demo-cash.json의 source=user_designation으로 기록하고 계좌 지문/설정 해시/최초 연결 시각을 SQLite user_cash_account에 보존했다. API 주문가능액에서 현금을 복사하지 않는다. 사용자 지정은 계산 기준으로 유효하며 broker_cash_verified=false는 출처 기록일 뿐 현금 계산을 막지 않는다.

- 계산 현금: 100000.000000 USD

새로 연결할 때 기존 보유/주문 이력이 있으면 임의로 기준을 덮어쓰지 않는다. 현재 모의계좌는 빈 보유·빈 조회 이력으로 기준을 등록했다. 이후 조회는 같은 계좌/설정 기준을 유지하며 재시작해도100000으로 초기화하지 않는다.

## 계산

현금(비용 전)=사용자 기준 현금-누적 매수체결금액+누적 매도체결금액. 확정 비용이 있으면 차감해 비용 후 현금을 계산한다. 같은 주문의 누적 체결을 대체하므로 중복 통보와 부분 체결을 이중 합산하지 않는다. 비용이 아직 없으면 비용 전 현금은 계산하고 비용 후 현금은None으로 둔다. 현재 실제 체결0이므로 차감할 기존 체결 비용은 해당 없음이다. 미래 비용0을 보장한 것이 아니다.

조회한 보유 수량과 누적 매수/매도 수량을 대조한다. 이력 누락·수량 불일치·과거 누적값 감소·계좌/설정 변경이면 계산을 갱신하지 않는다. 외부 입출금·배당·환전의 미제공 사건은 모델에 포함하지 않았다는 상태를 명시한다. 이 모델을 증권사 검증 현금/확정 손익으로 포장하지 않는다.

기존 조회기 collect_and_connect와 DemoExecutionPort.refresh가 계산값을 사용·반환한다. 기존 RiskProof·주문 승인·통합증거금·손실 한도·상품 정책은 변경하지 않는다. 신규 주문false, 실제 주문0. 사용자 지정 현금 연결이 계좌 서비스 설정이나 실제 주문 허가는 아니다.

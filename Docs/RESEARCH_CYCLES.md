# 반복 수정·검증 실행

```cmd
python main.py --test research
```

새 실행 인자를 추가하지 않고 기존 --test로 연결했다. 설정은 ../Config/research-cycles.json이다.
현재 기본값은 2026-06-13 이전 3년의 토스 일봉이다. 2026-06~10월 분봉 연구의 시험 기간과
겹치지 않는 역사 구간을 확보해 장기 가격·거래량 후보를 고르는 연구다.
일봉 결과를 장중 전략의 검증으로 간주하지 않는다. 과거 뉴스 기록은 아직 없다.

## 반복 순서

1. 기본 돌파: 과거 20/40일 최고가 돌파와 거래량 확인.
2. 추세 필터 추가: 100일 평균보다 높은 추세에서만 돌파 진입.
3. 반등 진입: 장기 추세 안에서 평균가격 위로 회복할 때 진입.

각 단계에서 손절 3/5%, 최대 보유 10/20일을 비교한다. 총 24개 후보/종목이다.
훈련 60%에 후보를 비교하고 각 단계 상위 3개를 검증 20%에서 비교한다.
시험 20%를 계산하기 전에 선택 규칙·시험 날짜·코드 지문을 frozen-candidates.json에 저장한다.
이 순서는 선택 과정에서 시험 가격을 사용하지 않기 위한 것이며 미래 수익을 보장하지 않는다.

기존 비용 가정을 유지한다. 다음 거래일 시가에 불리한 스프레드·슬리피지를 반영하고
손절 아래 갭은 낮은 시가로 청산한다. 따로 배당·기업행동·주문 지연·부분 체결을 재현하지 않는다.
각 구간은 새 가상 자금이며, 이전 구간 가격은 지표의 준비 데이터로만 쓴다.

## 결과 보존

- ../Data/history/daily/: 일봉 원자료·요청 기간·출처. 완료 캐시는 인증 없이 재사용한다.
- ../Data/history/daily-test-periods.json: 이전 시험 날짜. 다른 파일·봉 단위라도 날짜가 겹치면 재사용으로 표시한다.
- ../Data/tests/results/research-cycles/실행시각/: 후보 전체·거래 기록·보고서·그래프·고정 규칙·계산 소스 사본.
- ../Data/tests/results/research-cycles/latest.json: 최근 결과 폴더.

동일 코드·설정으로 재실행한 결과는 재현이다. 새 독립 실험으로 세지 않는다.
다른 규칙으로 같은 시험 기간을 계산하면 exploratory_test_reused이며 시험의 재사용을 숨기지 않는다.
이전 3년 자료의 검증은 현재보다 과거로 돌아간 추가 역사 검증이므로 향후 장중 검증이 필요하다.

통과 기준: 훈련/검증/시험 모두 양수, 훈련 10건·검증 5건·시험 30건 이상,
시험 단순 보유 초과, 낙폭 5% 이하, 2배 비용 양수, 시험 날짜 재사용 없음.
실패 조건을 낮춰서 통과시키지 않는다. 양수 후보가 있어도 실시간 전략으로 자동 적용하지 않는다.

자동 동작 검증은 `python main.py --test unit-research`다. 합성 입력으로 시각·비용·손절·미래 정보·날짜 겹침을 검사한다.

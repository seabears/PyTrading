# 현재 운용 엔진 백테스트

CMD에서 프로젝트 폴더로 이동한 다음 실행합니다.

```cmd
cd /d C:\Projects\PyTrading
python Code\main.py --test engine-backtest
```

`--test`만 입력한 기능 메뉴에서도 **현재 운용 엔진 그대로 30종목 공동 계좌 재생**을 선택할 수 있습니다.
실제 주문, 인증, 새 데이터 수집은 없습니다. 기존 모의 계좌와 시세 파일은 변경하지 않습니다.
실행할 때마다 별도 결과 폴더를 만듭니다.

- 종목·순서: `Config/settings.json`의 `symbols`.
- 판단 규칙: 같은 설정의 `strategy_config`가 지정한 `Config/strategy.json` + `strategy/engine.py` 기본값.
- 초기 자금·종목별 비중·동시 보유·거래 비용: `Config/paper.json`.
- 저장 시세: `Data/history/minute/US-종목.json`.
- 결과: `Data/tests/results/engine-backtest/실행시각/`.
- 가장 최근 결과 위치: 위 폴더의 `latest.json`.

결과에는 `report.md`, 계좌 수익·낙폭 `performance.png`, 30종목 기여 `stocks.png`,
실행 조건·원본 및 코드 SHA-256 `declaration.json`, 종목 기여 `attribution.json`,
조건별 전체 계좌·거래·곡선 JSON, 재현용 Python 소스 사본이 포함됩니다.
백테스트 실행 자체는 자동 검증 전체를 실행하지 않습니다. 자동 검증 명령은 아래와 같습니다.

```cmd
python Code\main.py --test unit-engine-backtest
python Code\main.py --test all
```

## 어떻게 같은 판단을 사용하는가

`research/engine_backtest.py`는 과거 자료를 운용 입력 형태인 스냅샷으로 변환합니다.
`ReplayAccount`는 `PaperAccount`의 반복 파일 저장만 생략하고,
`PaperAccount.evaluate_snapshot`과 `strategy.engine.evaluate`를 그대로 호출합니다.
신호·손절·이익 보호·재진입·수량·현금·수수료 계산을 따로 구현하지 않습니다.
현재 기능은 **미국 종목 공동 USD 계좌·뉴스 비활성·5분봉 전략**을 지원합니다.

과거 매수·매도 호가는 저장되어 있지 않습니다. 따라서 t까지 완성된 봉을 보고,
다음 1분봉의 시가를 t의 가상 중간 호가로 사용합니다. 현재 분의 고가·저가·종가·거래량은
미리 보지 않습니다. 같은 시가에서 스프레드·슬리피지·비용을 불리한 방향으로 적용합니다.
1분마다 지연 없이 판단·전량 체결된다는 가정은 실시간 수집과 다르며 결과가 낙관적일 수 있습니다.

네 조건은 결과를 보기 전에 고정합니다. 기본 비용, 수수료·슬리피지 제거,
해당 비용 두 배, 기본 비용에 스프레드 0.25%를 적용한 경우입니다.
비용이 매입 원가·보호 매도선·다음 거래에 영향을 주므로 조건 간 차이는 단순 비용 차감액과 다릅니다.
숫자를 바꾸려면 `tools/research_engine_backtest.py`의 `scenarios`를 수정합니다.
이를 바꿔 좋은 결과를 고르면 별도 미사용 기간에서 다시 평가해야 합니다.

현재 KIS 분봉은 약 한 달뿐이며 오래된 일봉을 분봉처럼 대체하지 않습니다.
기업행동·배당 현금·실제 세금·실제 호가·부분 체결·분 안의 급락 경로는 재현하지 못합니다.
순수익률은 미청산 보유의 가상 매도 비용까지 차감한 평가이며 강제 매도 거래를 만들지 않습니다.
완료 거래 Profit Factor와 평가손익을 함께 읽어야 합니다. 짧은 기간의 연율 수익률은 표시하지 않습니다.

## 자동 검증의 의미

합성 분봉으로 정상 파일 저장 계좌와 메모리 재생 계좌의 **매 시점 판단과 최종 상태**를 비교합니다.
미래 OHLCV와 진행 중인 분봉 값을 바꿔도 이전 판단이 유지되는지,
공동 자금·동시 보유 제한·종목 처리 순서·비용 손익·현금이 맞는지 확인합니다.
누락 분을 채우지 않는지, 휴장·장외를 제외하는지, 기존 설정을 변경하지 않는지도 확인합니다.
이 검증의 통과는 수익성을 의미하지 않습니다.

이 문서의 장비 이름, 사용자명 및 절대 경로는 공개용 예시다. 실제 환경에서는 로컬 값을 사용한다.

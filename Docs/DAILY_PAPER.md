# 고정 일봉 후보의 지속 모의 관측

실행: `python Code/daily_paper.py`. 계좌·대기 계획은 Data/paper-daily-frozen/account.json, 실제 관측은 decisions.jsonl, 확정 일봉 근거는 sources/거래일에 저장한다. 기본 실적 계좌·단기 가격 연구와 분리돼 있다.

Config/fixed-trend-study.json candidate의 donchian__trailing_atr_3p5를 재최적화하지 않았다. 55일 최고가 돌파, 20일 저점 매도, ATR 초기 2.5배/추적 3.5배, SPY 200일 시장 필터, 최대 126거래일을 사용한다. 후보 우선순위는 기존 모멘텀/변동성 순위다. 거래 위험은 후보의 0.25%와 공통 안전 한도 중 더 보수적인 값을 쓴다.

거래소 달력의 정규장 종료 후 2분이 지난 가장 최근 거래일만 사용한다. 진행 중인 일봉·미래 날짜가 들어오거나 해당 날짜 자료가 누락되면 새 계획을 보류하고 보유 가격 보호는 계속한다. 미완료·결측을 0이나 가짜 봉으로 채우지 않는다. 휴장·서머타임·조기 종료는 기존 exchange_calendars 달력을 재사용한다. 갑작스러운 거래 중단까지 달력이 입증하지 않으므로 실제 호가 신선도를 별도로 검사한다.

종가 신호를 다음 거래일 계획으로 저장한다. 재시작 시 동일 계좌의 대기 계획을 복원하고 동일 관측 시각·이미 처리한 계획은 이중 체결하지 않는다. 놓친 시가를 과거 차트에서 찾아 체결하지 않는다. 개장 전 또는 개장 후 5분 이내에 실행을 시작했다면 기존처럼 개장 5분 이내에만 매수한다. 개장 후 5분이 **지난 뒤** 실행을 시작한 경우에만 그 실행이 시작된 당일 정규장 종료 전까지 진입을 허용한다. 정확히 개장 5분에 시작한 경우는 예외가 아니다. 이 창을 놓치면 해당 매수를 취소한다. 시가 갭 3%·스프레드 0.3% 제한과 계좌 위험 검사를 통과해야 한다. 미수행 매도 계획은 다음 유효 관측까지 유지한다.

매수는 실제 관측 ask에 슬리피지 0.1%, 매수 비용 0.1%; 매도는 bid에서 슬리피지 0.1%, 매도 비용 0.2%를 적용한다. 실거래 요율이 아닌 모의 가정이다. 거래에는 quote_at·관측 at·reference_price·가상 price·비용을 남긴다. 부분 체결·시장 충격은 이 내부 계좌에서 재현하지 않는다. 증권사 부분 체결 상태 기계는 별도 orders.py다.

백테스트는 다음 날 시가와 일봉 내 고저가를 이용하지만 지속 모의는 첫 관측 호가에서만 체결한다. 실제 개장 체결을 보장하지 않고 장중 중간 급락·미관측 손절도 재현하지 못한다. 당일 고가로 갱신한 ATR 보호선은 완료 일봉 처리 후 다음 정규장부터 적용한다. 운영 안전 검사는 기존 백테스트보다 체결을 줄일 수 있다.

수정 일봉과 실시간 원본 가격을 결합하므로 기업행동 시 기준이 달라질 수 있다. 배당 현금·분할 수량 자동 조정·과거 전체 상장 종목 편향 보정은 구현하지 않았다. ASML 재수집 가격 변경처럼 원인이 불명확한 기업행동은 운영자가 근거를 확인해야 한다. 해당 의심 상태에서 신규 매수를 자동 승인하지 않도록 운영 중지 기능을 사용한다.

과거 재생·합성 테스트·실제 시세 관측·증권사 체결을 구분한다. 새로 다운로드한 과거 일봉은 미래 관측 실적이 아니다. 이전에 본 기간을 다시 최적화하지 않으며 최소 관측/거래 수·수익·낙폭 조건 충족은 연구 검토 자격일 뿐 실거래 승인으로 보지 않는다.


## 2026-10-27 관측 집계 보강

새 실행부터 observation-ledger.sqlite에 실제 관측·계획·체결·설정/원본 지문·재시작·중지 이력을 보존한다. decisions.jsonl 회전과 별개다. daily/US-거래일.json과 md는 이 원장의 일별 집계다. 과거 차트를 실시간 관측으로 소급 입력하지 않으며 기존 텍스트 로그도 자동 이관해 정상 관측으로 만들지 않는다.

프로세스 heartbeat와 정상 정규장 호가 시간을 구분한다. 정규장 시도·정상/누락/지연/오류·180초 초과 관측 공백을 기록한다. 180초는 진단 임계값이며 설정 대기 간격이 실제 주기라는 뜻이 아니다. 가동 시간은 확인된 짧은 heartbeat 구간만 합산하고 장시간 공백을 가동으로 채우지 않는다.

전일 신호·다음 거래일 계획·놓친 진입 창·미체결 사유·재시작 계획·매수 중지/복구/재개 이력을 남긴다. 계획이 0이면 입력 커버리지·지표 준비 여부·판단 사유로 데이터 부족과 실제 신호 부재를 구분한다. 매수 계획의 종료 사유와 가상 체결을 함께 추적한다.

현금·보유·평가액·실현/미실현 손익·비용·투자 비중은 정상 시세가 충분할 때만 평가한다. 정상 평가가 없으면 observed_mdd와 last_valid_valuation은 null이며 '0% 안정 수익'이 아니다. 이전 유효 평가를 현재 가치로 표현하지 않는다. 관측 기준 MDD는 관측 사이 급락을 놓칠 수 있다.

계좌 저장 뒤 보고서 기록이 유실된 경우 기존 권위 계좌의 live_observation 체결만 근거 복구하고 recovered_at/trade_at을 구분한다. 이 복구는 호가·정상 가동 시간·수익 구간을 생성하지 않는다. 회전 로그를 삭제해도 집계·원장 근거는 남는다. SQLite가 누적되므로 서비스 중지 후 일관된 backup API로 보관하고 용량 경계를 확인한다.

이전 확정 종가와 진입 호가가 20% 이상 괴리하면 corporate_action_or_price_mismatch로 진입을 취소하고 의심 근거를 남긴다. 3% 진입 갭 제한도 유지한다. 이 휴리스틱은 기업행동을 확정하거나 모든 소규모 조정을 탐지하지 못한다. 수량·원가는 자동 보정하지 않는다.

격리 관측 폴더는 PYTRADING_DAILY_DIR의 Data 하위 절대 경로로 지정한다. 기존 기본 계좌를 변경하지 않는다. 충분한 실제 20거래일·거래 표본 전까지 상태는 '관측 진행 중'이다.


## 2026-11-04 늦은 실행의 당일 진입 예외

사용자 요청에 따른 실행 시점 정책 변경이다. 5분은 KIS의 주문 제한이 아니라 다음 날 시가 부근에 진입하려고 두었던 프로그램 규칙이다. 고정 후보의 돌파·ATR·시장 필터는 변경하지 않았다. 늦은 시각 진입은 기존 시가 기준 백테스트와 다르며 수익성이 검증된 것으로 해석하지 않는다.

- 실행 시작 시각은 daily 서비스 진입 직후 한 번만 확보한다. 개장 전 실행했지만 일봉 수집·인증이 늦어진 경우는 예외를 얻지 못한다.
- 늦게 시작한 실행도 당일 실행 예정인 유효 매수 계획이 있어야 한다. 가격 괴리 3%, 스프레드, 시세 신선도, 계좌·비용·위험·매수 중지 검사를 그대로 통과해야 한다.
- 재시작은 새 실행 시작 시각으로 판단하고 남아 있는 대기 계획만 이어받는다. 이미 만료·소진한 계획을 되살리거나 과거 호가로 체결하지 않는다.
- 다음 거래일에는 전날의 늦은 시작 예외가 이월되지 않는다. 휴장·조기 종료는 기존 거래소 달력을 따른다. 매도·손절 시간 정책은 바뀌지 않는다.
- SQLite startup 이벤트에 정책 버전·실행 시작·해당 정규장 예외 여부를 남긴다. 내부 가상 매수 및 판단 결과에도 entry_timing을 남긴다. 증권사 모드는 같은 판단기를 사용하지만 접수·실제 체결은 원격 대조로만 확인한다.

CMD 실행은 프로젝트 루트에서 `python Code/daily_paper.py`, Pi 셸은 같은 설치 루트에서 `PYTRADING_SETTINGS=$PWD/Config/settings-linux.json .venv/bin/python Code/daily_paper.py`다. 실행 모드는 기존 Config/execution.json 설정을 따르므로 선택 상태를 먼저 확인한다. 이 코드 수정 자체로 서비스 시작·배포·주문 허용·부팅 설정은 바꾸지 않는다.

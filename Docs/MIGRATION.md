# PyTrading 이전

현재 작업 위치는 `C:\Projects\PyTrading\Code`입니다.

```cmd
cd /d C:\Projects\PyTrading\Code
python main.py
```

실제 주문 기능은 없습니다. 17종목 설정·뉴스 필터·매도 보호·모의 계좌와 연구 자료를 이전했습니다.
이전 PyTrading 전체 백업: `%USERPROFILE%\Documents\주식\migration-backups\PyTrading-20261013-214041\original-PyTrading`

Git 메타데이터는 저장소 루트에 유지했습니다. 계좌·인증 내용은 보고서에 출력하지 않았습니다.
기존 PyTrading 보유 CSV·추천 상태·KIS 토큰은 백업에 보존했고 새 모의 계좌에 병합하지 않았습니다.
이전 C 드라이브 프로그램은 복구용으로 유지합니다. 앞으로 수정·실행은 Code 폴더에서 합니다.

이 문서의 장비 이름, 사용자명 및 절대 경로는 공개용 예시다. 실제 환경에서는 로컬 값을 사용한다.
